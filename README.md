# Thuy Duong SSI Recruitment Landing

Landing/bio tuyen dung cho Thuy Duong Invest.

## Run Local

```powershell
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:3000
```

## Env

Copy `.env.example` to `.env.local` and fill:

```env
LARK_APP_ID=
LARK_APP_SECRET=
LARK_BASE_APP_TOKEN=
LARK_TABLE_ID=
```

When Lark env is missing, `/api/leads` returns `503` with a safe public message.
